# docs/BEST_PRACTICES.md — Минимальный свод принципов "не neuro-slop" сайта

> Короткий файл-подкачка для Этапов 5–6. Не пытается быть исчерпывающим учебником —
> только то, что реально снижает риск получить типовой "AI-лендинг".

## Как избежать "нейро-слопа"

- Не использовать шаблонные формулировки уровня "Добро пожаловать на наш сайт" /
  "Мы предлагаем лучшие товары" / generic hero-текст без конкретики.
- Не ставить одинаковые по смыслу 3 карточки "иконка + заголовок + абзац" без вариативности —
  разнообразить композицию блоков (не всё в сетке 3×N).
- Избегать избыточных градиентов, глянцевых 3D-иконок, стоковых "улыбающихся людей" —
  для этого проекта уместнее фактурные фото реальных изделий и мастерской.
- Каждый визуальный блок должен иметь понятную причину именно такой формы (не "потому что так делают все AI-лендинги").
- Живой, конкретный текст важнее "продающих" общих фраз: реальные детали (материалы, процесс, история) сильнее общих обещаний.

## Структура и навигация (общие принципы)

- Один сайт — одна чёткая главная задача на странице (не смешивать 5 CTA на одном экране).
- Понятная иерархия: заголовок → подзаголовок → тело → действие, без визуального шума.
- Логичный порядок разделов от общего к частному (обзор → детали → доверие/контакты).
- Навигация — не больше 5–7 основных пунктов, ясные названия разделов, никаких загадочных ярлыков.

## Mobile-first (обязательно)

- Проектировать сначала под 360–390px, расширять вверх через `min-width` медиа-запросы.
- Тап-зоны от 44–48px, текст от 16px, отсутствие горизонтального скролла.
- Не полагаться на hover-эффекты как на единственный способ показать важную информацию.
- Изображения адаптивные (`max-width:100%; height:auto;`), тяжёлые — с `loading="lazy"`.

## Производительность (по минимуму, но обязательно)

- Сжимать изображения перед публикацией, использовать современные форматы, где уместно.
- Не подключать лишние библиотеки/шрифты ради одного эффекта.
- Проверять сайт на реальном телефоне, а не только в эмуляторе браузера.

## Доверие и содержание для витрины/магазина

- Понятные условия (доставка, уход, оплата) — не прятать в дальний угол.
- Контакты и способ связи с мастером — всегда доступны в 1–2 клика с любой страницы.
- Реальные фото процесса и мастера повышают доверие сильнее декоративных иллюстраций.
